# CDN Vanilla Example

Minimal single-file demo — no bundler, no local install. Loads the library from jsDelivr, creates a ClipNode with a generated tone, and provides Play / Pause / Resume buttons.

See the [playground](../playground/) example for the full feature set.

> **Note:** Opening the file directly with `file://` will not work because browsers block worklet loading from local origins. Use any static file server, or run `bun run examples` from the repo root.
