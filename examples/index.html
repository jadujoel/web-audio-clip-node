Examples

Six integration paths for the custom Audio Worklet Node — from a zero-build CDN snippet to a full streaming React app.

  • 🎛️ Playground→

    Full-featured interactive demo showcasing all controls, parameters, linked pairs, tempo, and loop settings.

    Bun · React
  • 🌐 CDN Vanilla→

    Single HTML file. No build step — loads the jsDelivr bundle directly and plays a generated demo clip.

    No build
  • 📦 ESM Bundler→

    Bun + TypeScript importing the package as an ES module. Standard bundler workflow.

    Bun
  • ⚛️ React→

    Bun + React using the built-in hooks and UI controls — the full interactive demo.

    Bun · React
  • 🗄️ Self-Hosted→

    Serve your own processor.js via getProcessorModuleUrl() for full control over asset hosting.

    Bun
  • 🎵 Streaming→

    Decode and buffer audio on-the-fly from a network stream via a dedicated Worker — minimal latency start.

    Bun · Worker
